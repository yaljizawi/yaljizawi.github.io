# Yazan Al-Geizawi — Engineering Portfolio

Personal portfolio covering power electronics, electric machines, and real-time motor drive control.

Site address after GitHub Pages is enabled: https://yaljizawi.github.io/

## Publish

1. Create a **public** GitHub repository named `yaljizawi.github.io` under the `yaljizawi` account.
2. Upload or push the contents of this folder to the repository root on the `main` branch. `index.html` and `assets/` must be at the root, rather than inside an extra folder.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/ (root)**, and save.
4. Wait for the Pages deployment to finish, then open https://yaljizawi.github.io/.

The `.nojekyll` file preserves the site as plain static HTML, CSS, and JavaScript.

## Update

Edit `index.html`, `styles.css`, or `app.js`, or add media under `assets/`, and commit the updated files to `main`. GitHub Pages will deploy the update.

## Media and project details

The site includes thirteen project stories, research publications, experience, supplied photography, technical figures, videos, and a downloadable resume. The SiC oscilloscope capture retains the original image data and uses CSS color inversion for display.

## Local preview

Serve this folder with a static HTTP server. No dependency installation or build step is required.

The full technical presentation is excluded from the published website. Only selected project figures and descriptions are included.
